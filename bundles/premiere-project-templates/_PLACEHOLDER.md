# Premiere Pro Project Templates

Place your `.prproj` project template files here. The receiver installs them into a single user-visible folder (NOT a Premiere version folder):

`Documents\MCM Vault Presets\Project Templates\`

To use a template: in Premiere Pro, **File → Open Project**, browse to that folder, and pick a `.prproj`. Premiere will open it. Save As to start a new project from the template.

Project templates are version-agnostic and cross-platform — Premiere auto-upgrades older project files when opened.
