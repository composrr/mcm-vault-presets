# Premiere Pro Workspaces

Place your workspace `.xml` files here. The receiver installs them into:

- **Windows:** `Documents\Adobe\Premiere Pro\<ver>\Profile-<user>\Layouts\`
- **Mac:** `~/Documents/Adobe/Premiere Pro/<ver>/Profile-<user>/Layouts/`

To export a workspace from Premiere Pro: arrange your panels how you want, then **Window → Workspaces → Save as New Workspace**. The saved layout is written to that Layouts folder as an `.xml` file. Copy it here.

Workspaces are cross-platform — the same `.xml` works on both Windows and Mac.
